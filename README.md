# TweeterIris

TweeterIris is a Data-Driven Real-Time Processing System for scalable big data analytics and auto-scaling architecture optimization.

TweeterIris is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TweeterIris.git`
2. `cd TweeterIris`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TweeterIris, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
